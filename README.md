# تارنور

فروشگاه تخصصی تجهیزات شبکه؛ روتر، سایر تجهیزات اکتیو، تجهیزات وایرلس، VoIP، مودم، کارت شبکه، هاب و سوییچ، پاورلاین و پرینت سرور.

- یک فایل `index.html` بدون نیاز به build؛ کافی است در مرورگر باز شود.
- ویدیوهای پس‌زمینه در پوشه `media/` از [Pexels](https://www.pexels.com/license/) هستند (استفاده تجاری رایگان).
- قیمت‌ها و موجودی کالاها نمونه هستند و باید با اطلاعات واقعی جایگزین شوند.

- نسخه دوم با تم سفید و قرمز شیشه‌ای در پوشه `v2/` است (`v2/index.html`).
- نسخه سوم، همه پنجره‌ها و تیترها شیشه‌ای، در پوشه `v3/` است.
